#  Contexto e Objetivos

## Tema Escolhido

**Introdução à Programação até Nível Intermediário e Aplicações de Inteligência Artificial utilizando Python.**

Este projeto foi desenvolvido como parte do desafio da DIO, utilizando o NotebookLM como ferramenta de apoio aos estudos e organização do conhecimento.

## Objetivos de Estudo

* Compreender os fundamentos da programação.
* Desenvolver lógica de programação.
* Aprender Python do básico ao intermediário.
* Entender Programação Orientada a Objetos (POO).
* Conhecer estruturas de dados e algoritmos básicos.
* Explorar conceitos fundamentais de Inteligência Artificial.
* Aplicar Machine Learning em projetos simples.
* Aprimorar habilidades de pesquisa utilizando IA.

#  Engenharia de Prompts

## Caso 1 — Lógica de Programação

### Prompt Inicial

"Explique lógica de programação."

### Problema

Resposta muito genérica.

### Prompt Refinado

"Explique lógica de programação para um iniciante utilizando exemplos simples em Python."

### Resultado

Resposta mais prática e fácil de compreender.

### Aprendizado

Quanto mais contexto é fornecido, melhor a qualidade da resposta.

---

## Caso 2 — Plano de Estudos

### Prompt Inicial

"Como aprender Python?"

### Problema

Sugestões muito amplas.

### Prompt Refinado

"Crie um plano de estudos de 60 dias para aprender Python e Inteligência Artificial."

### Resultado

Cronograma estruturado por etapas.

### Aprendizado

Definir prazo e objetivo gera respostas mais específicas.

---

## Caso 3 — Inteligência Artificial

### Prompt Inicial

"Explique IA."

### Problema

Definições superficiais.

### Prompt Refinado

"Explique a diferença entre IA, Machine Learning e Deep Learning utilizando exemplos do cotidiano e exemplos em Python."

### Resultado

Maior clareza e contextualização.

### Aprendizado

Solicitar exemplos práticos melhora significativamente o aprendizado.

#  Cicatrizes e Troubleshooting

Durante o processo foram encontrados alguns desafios:

| Problema                  | Solução                          |
| ------------------------- | -------------------------------- |
| Respostas muito genéricas | Fornecer mais contexto           |
| Falta de exemplos         | Solicitar exemplos em Python     |
| Explicações complexas     | Pedir explicação para iniciantes |
| Excesso de teoria         | Solicitar aplicações práticas    |
| Conteúdo muito extenso    | Pedir resumos e tópicos          |

## Principal Aprendizado

A qualidade das respostas está diretamente relacionada à qualidade dos prompts elaborados.

#  Glossário

| Termo            | Definição                                     |
| ---------------- | --------------------------------------------- |
| Algoritmo        | Sequência de passos para resolver um problema |
| Variável         | Local utilizado para armazenar dados          |
| Função           | Bloco reutilizável de código                  |
| Classe           | Estrutura que define objetos                  |
| Objeto           | Instância de uma classe                       |
| Dataset          | Conjunto de dados                             |
| IA               | Inteligência Artificial                       |
| Machine Learning | Aprendizado baseado em dados                  |
| Deep Learning    | Redes neurais profundas                       |
| API              | Interface de comunicação entre sistemas       |

#  Conclusão

O desenvolvimento deste caderno temático permitiu consolidar conhecimentos desde os fundamentos da programação até conceitos intermediários e aplicações iniciais de Inteligência Artificial.

Além da evolução técnica, o projeto demonstrou a importância da engenharia de prompts, da curadoria de fontes confiáveis e do uso da Inteligência Artificial como ferramenta de aprendizagem ativa.

O NotebookLM mostrou-se uma excelente plataforma para organizar conteúdos, gerar resumos, criar conexões entre materiais e acelerar o processo de aprendizagem, contribuindo para uma jornada de estudos mais eficiente e estruturada.
